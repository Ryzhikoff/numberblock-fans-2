# Scene_75 — Сотня пугается Пяти тысяч

Короткий вертикальный ролик длительностью ровно 10 секунд.

## Сюжет и тайминг

| Время | Действие |
|---|---|
| 0.00–1.55 | Сотня идёт и улыбается |
| 1.55–2.20 | На Сотню наваливается тень Пяти тысяч |
| 2.20–2.65 | Сотня удивлённо смотрит в сторону тени |
| 2.65–3.70 | Камера перемещается к Пяти тысячам |
| 3.70–4.25 | Пять тысяч смотрит сверху вниз-влево на Сотню |
| 4.25–5.10 | Камера возвращается к Сотне |
| 5.10–6.60 | Сотня пугается (1,5 секунды) |
| 6.60–6.85 | Сотня распадается на 100 единиц |
| 6.85–10.00 | Единицы разбегаются в разные стороны |

## Запуск

1. Открой `Assets/Scenes/Scene_75.unity`.
2. Выбери в Game View вертикальный формат 9:16 (например, 1080 × 1920).
3. Нажми Play. Сцена отыгрывается автоматически.

Если сцену нужно пересобрать, используй `Tools → Scene_75 → Quick Setup Scene`.

Все новые варианты блоков, материалы и сгенерированные лица находятся в
`Assets/Prefabs/Blocks/Scene75/`.
