# Scene_71 — Восхождение треугольных чисел

**Концепция:** пирамидка чисел растёт по треугольной последовательности
`1 → 3 → 6 → 10 → 15 → 21 → 28 → 36 → 45 → 55`.
На шаге *k* к фигуре добавляется ряд из *k* единиц: текущая фигура рассыпается на
единицы, справа-сверху прилетают новые единицы, все занимают места треугольника,
в момент касания — вспышка, и единицы сливаются в **цельный треугольный блок**
со своим цветом и одним лицом.

Форма — симметричная «пирамидка»: нижний ряд *k* кубов, выше *k−1*, … вершина 1 куб по центру.

**Раскладка вложенная (perfect-nest):** кубы стоят по формуле `x = r*0.5 + c + 0.5, y = r + 0.5`
(пивот в левом-нижнем углу). Каждый ряд симметричен относительно центра, но при этом
T(k−1) ТОЧНО совпадает с левой-нижней частью T(k). Поэтому новые единички при росте
стыкуются к граням существующего блока **впритык, без сдвига** — блок не рассыпается,
к нему по правой грани и вершине прилетают k единиц, затем вспышка → цельный T(k).

## Файлы
| Файл | Назначение |
|------|------------|
| `Assets/Scripts/TriangularBlock.cs` | Маркер треугольного числа (step + number). `Scale` тут неприменим — форма не параллелепипед |
| `Assets/Scripts/Editor/S71_TriangularBlockGenerator.cs` | Генерирует префабы T1..T55 |
| `Assets/Scripts/S71_Main.cs` | Контроллер анимации (прилёт → слияние) |
| `Assets/Scripts/Editor/S71_SceneSetup.cs` | Быстрая настройка сцены |
| `Assets/Prefabs/Blocks/Triangular/` | **Новые** префабы (отдельная папка, переиспользуемые) |
| `Assets/Prefabs/Blocks/Triangular/Materials/` | **Копии** материалов цвета/лица (правка не ломает оригинальные блоки) |

## Как запустить
1. **Сгенерировать блоки:** меню `Tools → Scene_71 → Generate Triangular Blocks`.
   Появятся `T1, T3, T6, T10, T15, T21, T28, T36, T45, T55` в `Prefabs/Blocks/Triangular/`.
   **Повторный запуск безопасен:** если префаб уже есть, генератор ПЕРЕИСПОЛЬЗУЕТ его текущие
   материалы и лица (файлы .mat не трогает), обновляя только геометрию. Все правки цвета/лиц сохраняются.
2. Создать/открыть сцену `Scene_71`.
3. **Настроить сцену:** меню `Tools → Scene_71 → Quick Setup Scene`
   (создаст GameManager, камеру, свет, UI и подставит префабы).
4. `Play` — или запись через **Unity Recorder**.

## Цвета и лица
- **1, 3, 6, 10** — цвет и лицо берутся из готовых блоков (их **копии** в `Triangular/Materials/`).
- **15, 21, 28, 36, 45, 55** — готовых ассетов нет: генерируется уникальный цвет
  (суффикс `_placeholder`) и подставляется лицо-заготовка. Замени текстуры в
  `Triangular/Materials/` на свои — оригинальные блоки при этом не пострадают.

## Что можно крутить (инспектор S71_Main)
- **Тайминг:** `flyDuration`, `mergePause`, `holdAfterMerge`, `perBlockStagger`.
- **Прилёт:** `spawnOffset` (откуда летят единицы), `spawnJitter`.
- **Камера:** `cameraOffset`, `cameraBackPerHeight` (авто-отъезд по мере роста фигуры).
- **Звук:** `flySound`, `mergeSound`, `finaleSound`, `backgroundMusic`,
  `playNumberVoice` (озвучка числа из `Resources/sound/<N>`).

## Заметки
- Лицо кладётся на переднюю (−Z) грань нижнего центрального куба — камера смотрит с −Z.
  Встроенный Quad лицевой стороной смотрит в −Z, поэтому поворот не нужен (`identity`).
- Повторный запуск генератора перезаписывает префабы и материалы в `Triangular/`.
