# Scene 78 — «Тысяча приземляется»

Вертикальный шорт 9:16 длительностью ровно 10 секунд.

## Сюжет

- `0.00–3.00` — семь весёлых Единиц идут по поляне под бодрую музыку.
- `3.00–3.95` — сверху ускоренно падает оригинальный блок 1000; под ним растёт тень.
- `3.95` — удар с двумя слоями звука, тряской камеры и клубами пыли.
- `3.95–5.50` — Единицы разлетаются в разные стороны и покидают кадр.
- `4.35` — обычное лицо 1000 меняется на отдельную прозрачную ухмылку.
- `6.10–10.00` — камера приближается и удерживает финальную ухмылку.

## Главные файлы

- `Assets/Scenes/Scene_78.unity`
- `Assets/Scripts/S78_Main.cs`
- `Assets/Scripts/Editor/S78_SceneSetup.cs`
- `Assets/Prefabs/Blocks/Scene78/Thousand_Smirk.prefab`
- `Assets/Prefabs/Blocks/Scene78/FaceTextures/Thousand_Smirk.png`

`Thousand_Smirk.png` — RGBA-текстура только с лицом. Красная сетка 1000 находится
на отдельной нижней плоскости, поэтому прозрачные области лица не закрывают линии кубиков.
Плоскость ухмылки копирует размер, поворот и положение оригинальной лицевой плоскости.

## Пересборка и проверка

- `Tools > Scene_78 > Quick Setup Short`
- `Tools > Scene_78 > Validate Short`

Для просмотра выберите в Game View формат `9:16` и нажмите Play.
